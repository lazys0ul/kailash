# Kailash Enterprises Website

A professional business website built with React, Vite, and Tailwind CSS featuring smooth animations, responsive design, and modern UX.

## 🚀 Features

- **Responsive Design** - Mobile-first approach with optimized layouts
- **10+ Custom Animations** - Smooth transitions, floating elements, ripple effects
- **React Router** - Fast client-side navigation with HashRouter
- **Error Boundary** - Graceful error handling with user-friendly UI
- **SEO Optimized** - Meta tags, Open Graph, and Twitter Cards
- **Accessibility** - Focus styles, reduced motion support, ARIA labels
- **Production Ready** - Zero errors, optimized build (80KB gzipped)

## 🛠️ Tech Stack

- **React 19.2.0** - Latest stable release
- **Vite 7.2.4** - Lightning-fast build tool
- **Tailwind CSS 4.1.17** - Utility-first CSS framework
- **React Router 7.10.1** - Declarative routing

## 📦 Getting Started

```bash
# Install dependencies
npm install

# Start development server (http://localhost:5173)
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview

# Run linter
npm run lint
```

## 📁 Project Structure

```
src/
├── components/     # Reusable components (Navbar, Footer, etc.)
├── pages/          # Route pages (Home, About, Services, Contact)
├── assets/         # Static assets
├── App.jsx         # Main app component with routing
├── main.jsx        # React entry point
└── index.css       # Global styles & animations

public/             # Public assets
dist/               # Production build output
```

## 🚢 Deployment

1. Build the project: `npm run build`
2. Upload contents of `dist/` folder to your hosting provider
3. Configure server to serve `index.html` for all routes

**Hosting Options:**
- Hostinger (shared hosting)
- Vercel (automatic deployments)
- Netlify (continuous deployment)
- GitHub Pages
