# Kailash Enterprises Website

A professional, clean, and modern static website for Kailash Enterprises built with React, Vite, and Tailwind CSS.

## Features

- Responsive design
- Multi-page navigation
- Optimized for performance
- Ready for deployment on shared hosting

## Tech Stack

- React
- Vite
- Tailwind CSS
- React Router

## Getting Started

1. Install dependencies: `npm install`
2. Start development server: `npm run dev`
3. Build for production: `npm run build`

## Deployment

The built files in the `dist` folder can be deployed to any static hosting service like Hostinger.
